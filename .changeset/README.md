# Changesets

## Current alpha validation

`pre.json` keeps releases in `alpha` prerelease mode for npm Trusted Publisher validation.
The four existing changeset IDs in `pre.json.changesets` are intentionally deferred
so this round only versions `react`, `reactive-react`, `antd`, and `antd-mobile`.
Keep those existing Markdown files for the subsequent stable release.
Do not run `changeset pre exit` during alpha validation: it prepares stable releases.
