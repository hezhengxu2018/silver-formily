# Changesets

## Stable releases and deferred React packages

Prerelease mode has ended (`pre.json` has been removed).
The next `pnpm version-packages` prepares stable releases from the retained changesets.
All remaining alpha versions belong to the four deferred packages below.
Removing the pre state directly avoids the Changesets 2.x exit path assigning
invalid versions to unversioned private docs apps.

`privatePackages.version` and `privatePackages.tag` are disabled so private
workspaces, including unversioned docs apps, do not receive versions or tags.

The following packages are temporarily excluded from releases:

- `@silver-formily/react`
- `@silver-formily/reactive-react`
- `@silver-formily/antd`
- `@silver-formily/antd-mobile`

They are listed in `config.json`'s `ignore` array to defer their changesets and
marked `private: true` in their package manifests to prevent publication.
Keep their changeset files until these packages are ready for release.
Do not mix ignored and non-ignored packages in the same changeset.

To resume releases for these packages, remove them from `ignore` and remove
`private: true` from their package manifests before running `pnpm version-packages`.
