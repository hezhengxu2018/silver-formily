# Field

## 描述

作为 `@silver-formily/core` 中 [createField](https://core.silver-formily.org/api/models/Form#createfield) 的 React 实现，它是专门用于将 ViewModel 与输入控件做绑定的桥接组件，Field 组件属性参考 [IFieldFactoryProps](https://core.silver-formily.org/api/models/Form#ifieldfactoryprops)

name 属性必填。

`Field` 与 `ArrayField`、`ObjectField`、`VoidField` 使用相同的挂载生命周期处理。StrictMode 同步重放 effect 时，不会额外触发字段的 `onFieldMount` / `onFieldUnmount`；字段实例变化或真正卸载时仍正常清理。真正卸载的清理延迟到微任务执行，因此不要在移除组件后立即同步读取 `unmounted` 来判断清理是否完成。

:::tip 提示
只有 `component` / `decorator` 元组中的 props 会传给对应组件，任意顶层 Field 属性不会自动展开到 UI 组件。数据字段注入 `value`、`onChange`、`onFocus`、`onBlur`，事件先更新模型，再调用最新的同名组件回调。组件显式传入的 `disabled` / `readOnly` 优先于字段 pattern 推导值；checkbox 等使用不同值属性的组件可通过 `connect` / `mapProps` 适配。
:::

`hidden` 与 `none` 都不渲染内容；Core 对 `hidden` 保留值，对 `none` 移除值并在恢复显示时恢复缓存值。字段模型是否挂载与内部 UI 是否可见是不同概念。

`children`（含渲染函数结果）与 `field.content ?? field.componentProps.children` 合并渲染，数值 `0` 是有效内容。未配置 component 时仍渲染内容。组件和装饰器可以是原生标签名或 React 组件；Schema 注册名称通过 `SchemaComponentsContext` 解析。

Core 将 `title`、`description`、`content` 声明为 `any`，放入 React 渲染树的内容仍须是合法 ReactNode。表中 display/pattern 默认值以没有父字段或表单状态覆盖为前提。
