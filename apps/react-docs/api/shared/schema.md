# Schema

`@silver-formily/react` 不导出 `Schema`。如果你在 React 侧 API 中看到 `Schema`、`ISchema`、`x-reactions`、`x-component-props` 等协议名，它们都属于 [`@silver-formily/json-schema`](https://json-schema.silver-formily.org/)。此处不再重复维护。

::: tip 迁移说明
本站 demo 与示例中的 Schema 相关代码统一从 `@silver-formily/json-schema` 导入类型。`@silver-formily/react` 文档只解释 React 侧如何消费 Schema，不重复维护 JSON Schema 协议本身。
:::
