# observer

## Description

observer is exported from [@silver-formily/reactive-react](https://reactive-react.silver-formily.org/), with a completely identical API. Using observer mainly gives components reactive update capabilities.

In `@silver-formily/react`, any custom component that reads reactive models such as Form / Field must be wrapped with observer, otherwise the component will not update as the data changes.
