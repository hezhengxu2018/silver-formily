# @silver-formily/antd

Ant Design 6 form components for Silver Formily on React 18/19.

## Components

Form, FormItem, FormLayout, FormGrid, FormButtonGroup, Input (including TextArea), Select, NumberPicker, PreviewText, Submit and Reset.

This is an intentionally partial migration of [Alibaba Formily's antd package](https://github.com/alibaba/formily/tree/d9a46442a575aa5f0fc1bd945e34d9a85d191d0e/packages/antd) (`@formily/antd@2.3.7`). Arrays, date/time pickers, upload, tree controls and scene components are not included.

## Usage

```tsx
import { Form, FormItem, Input, Submit } from '@silver-formily/antd'
import { createForm } from '@silver-formily/core'
import { Field } from '@silver-formily/react'
import { useState } from 'react'

export default function Example() {
  const [form] = useState(() => createForm())
  return (
    <Form form={form} onAutoSubmit={values => console.log(values)}>
      <Field name="name" title="Name" required decorator={[FormItem]} component={[Input]} />
      <Submit>Submit</Submit>
    </Form>
  )
}
```

Styles load with component imports. Ant Design 4 Less files and `@formily/*` imports are not supported.

## Migration notes

- Upstream baseline: `d9a46442a575aa5f0fc1bd945e34d9a85d191d0e` on `formily_next`.
- State and React bindings use the local `@silver-formily/*` packages.
- ESM and declarations are generated by tsdown into `esm/`.
- Scoped CSS consumes `ConfigProvider` theme tokens, with no old Ant Design Less imports.
- FormItem retains its layout and field mapping; input wrappers consume status/size through context. Appearance uses native ConfigProvider variant inheritance.
- PreviewText only includes the three migrated input families and shared placeholder APIs.
- FormLayout preserves responsive and shallow/deep settings, including explicit false values.
- FormGrid shares the local Grid runtime with the Element Plus wrapper, providing container-responsive columns, FormItem/GridColumn spans, and externally controlled collapsible query forms. Use `gridSpan={-1}` to fill the current row's remaining columns.
- Sticky uses measured fixed positioning constrained to its owning Form. It defaults to the bottom; use `position="top"` (or `bottom={false}`) for top attachment. An explicit `container` overrides the form boundary.
- Replace legacy FormItem/FormLayout bordered={false} with variant="borderless". Form, FormLayout and FormItem support outlined, filled, borderless and underlined; explicit control variants take precedence.
- Ant Design control props follow v6, including `variant`, `open` and `orientation`.
- Submit guards repeated clicks and native/programmatic double submission. Reset reports validation feedback after the core reset promise settles.
