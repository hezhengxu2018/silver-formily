[简体中文](https://github.com/hezhengxu2018/silver-formily/blob/main/packages/designer-shared/README.md) | [English](https://github.com/hezhengxu2018/silver-formily/blob/main/packages/designer-shared/README.en.md)

Shared designer utilities for coordinates, DOM events, scrolling, subscriptions, and scheduling.

> This is an internal workspace (`private: true`) and is not published to npm.

## Installation

```bash
pnpm --filter '<workspace-name>' add '@silver-formily/designer-shared@workspace:*'
```

Replace `<workspace-name>` with the consuming workspace name.

## Features

Low-level utilities shared by the designer engine and bindings; public exports are defined in `src/index.ts`.
