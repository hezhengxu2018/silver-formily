Vue 3 bindings and interface components for the Silver Formily designer.

> This is an internal workspace (`private: true`) and is not published to npm.

## Installation

```bash
pnpm --filter '<workspace-name>' add '@silver-formily/designer-vue@workspace:*'
```

Replace `<workspace-name>` with the consuming workspace name.

## Features

Provides containers, hooks, widgets, context, and shared entry points connecting designer models to the Vue interface.
