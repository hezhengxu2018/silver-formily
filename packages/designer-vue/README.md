Silver Formily 设计器的 Vue 3 绑定与界面组件。

> 本包为仓库内部工作区（`private: true`），不发布到 npm。

## 安装

```bash
pnpm --filter '<workspace-name>' add '@silver-formily/designer-vue@workspace:*'
```

将 `<workspace-name>` 替换为消费该包的工作区名称。

## 功能

提供 containers、hooks、widgets、context 与 shared 入口，连接设计器模型和 Vue 界面。
