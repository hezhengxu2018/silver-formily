`@silver-formily/element-plus` 是对 `@formily/element-plus` 的一次重构。

## 安装

```bash
pnpm add \
  @silver-formily/element-plus \
  @silver-formily/core \
  @silver-formily/grid \
  @silver-formily/json-schema \
  @silver-formily/reactive \
  @silver-formily/reactive-vue \
  @silver-formily/shared \
  @silver-formily/vue \
  @vueuse/core \
  'element-plus@^2.11.0' \
  'vue@^3.3.0'
```

安装命令包含必需的 peer 依赖；已有项目请保留满足版本范围的现有依赖。
