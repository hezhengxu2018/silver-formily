# Reactive React Guide (extends root `AGENTS.md`)

This package provides the React bindings for Silver Formily’s reactivity engine, migrated from `@formily/reactive-react@2.3.7`. Follow the global conventions defined in the repository root, then apply the details below when working inside `packages/reactive-react`.

## Source Layout

- `src/` mirrors the public API surface. Do not import from `dist/` or reach into other packages’ `src/` folders.
- `src/observer.tsx` holds the `observer` HOC and the `Observer` component; `src/hooks/` holds the React hooks; `src/shared/` holds StrictMode/GC helpers.
- `dist/` is generated by tsdown (`pnpm build`). Treat it as read-only—changes there will be discarded.

## Upstream Divergence

Deliberate differences from `@formily/reactive-react` — keep them when syncing upstream changes:

- Hooks are exported **without** the `unstable_` prefix (`useObserver`, `useCompatEffect`, `useCompatFactory`). `useForceUpdate`, `useDidUpdate`, and `useLayoutEffect` are internal helpers: keep their direct module imports inside the package and do not re-export them or list them in user-facing API documentation.
- Peer dependencies are `react`/`react-dom` `^18 || ^19` plus the existing `@silver-formily/shared` compatibility peer; `react-is` was dropped (it is a transitive dependency of `hoist-non-react-statics`).
- `useCompatEffect` retains both setup and cleanup across synchronous StrictMode replay. A per-render token is compared only during effect setup; a new committed setup disposes the previous resource first. Dependency comparison is delegated to React (`Object.is`), including `NaN` and signed zero. Do not read render-written dependency refs during cleanup: abandoned renders must not change committed subscriptions.
- `useComputed`, `useAutorunEffect`, and `useReactionWatch` establish and dispose reactions in ordinary effects. They do not need render-time GC. Latest callbacks are published after commit; use `deps` to rebuild tracking for non-observable inputs.
- `observer` supports function components, `memo` (preserving comparators), and `forwardRef`. Keep generic function signatures and custom statics in its public types. React 19 ref props are preserved; React 18 function components receiving refs must use `{ forwardRef: true }` or a `forwardRef` input.
- `src/shared/global.ts` (`globalThisPolyfill`) was removed—React 18/19 environments all ship native `globalThis`; `gc.ts` reads `globalThis.FinalizationRegistry` directly.
- `immediate` schedules via native `queueMicrotask` instead of upstream’s `Promise.resolve().then` carrier (the cancel-wrapper semantics are unchanged).
- ESM-only output in `dist/` (`.mjs` + `.d.ts`), built with tsdown instead of upstream’s `tsc + rollup` combo.
- `observer.tsx` uses the automatic JSX runtime (`jsx: react-jsx`, overridden in this package’s `tsconfig.json`); React is only imported as a type.

## Commands

| Script                      | When to run                                                    | Notes                                                                                                 |
| --------------------------- | -------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------- |
| `pnpm build`                | Before publishing or when other packages need fresh artifacts  | Runs tsdown to emit ESM + d.ts into `dist/`.                                                          |
| `pnpm dev`                  | Local development                                              | `tsdown --watch`; re-builds on change, but still writes into `dist/`.                                 |
| `pnpm test`                 | Before merging behavior changes                                | Vitest browser mode (Chromium via Playwright, same as `element-plus`); `test:coverage` runs headless. |
| `pnpm check-types`          | Whenever TypeScript config changes or you see editor anomalies | Uses plain `tsc --noEmit` (no `vue-tsc` here).                                                        |
| `pnpm format` / `pnpm lint` | Required before commits                                        | Delegated through root Turborepo tasks to ensure ESLint passes.                                       |

## Coding Conventions

- Export through `src/index.ts` only. If you need sub-path exports, add them to `package.json#exports`.
- Peer dependencies (`@silver-formily/reactive`, `react`, `react-dom`) are externalized at build time. Don’t bundle them.
- Keep comments that explain StrictMode/ConcurrentMode workarounds—they encode non-obvious React behaviors.
- macOS note: file names are case-insensitive, so `Observer` component tests live in `tests/observer.test.tsx` rather than a separate `Observer.test.tsx`.

## Testing & Verification

- Tests run in a real browser via Vitest browser mode (see `vitest.config.ts`): Playwright provider, Chromium instance, `vitest-browser-react` for rendering.
- `render`/`rerender`/`unmount` from `vitest-browser-react` are async—always `await` them. Assertions use locators (`await expect.element(...)`), which auto-retry and naturally absorb reactive re-renders—no manual `act()` wrapping.
- Prefer real rendering over mocking React—the package’s value is its integration with React’s render pipeline.
- Before `pnpm release`, run `pnpm build && pnpm test && pnpm check-types` and inspect `dist/` for unexpected diffs.

## Docs Dependencies

- The dedicated docs site lives in `apps/reactive-react-docs`. Public API and behavior changes must update both `api.md` and `en/api.md`, the relevant demos, and this package’s `CHANGELOG.md`.
