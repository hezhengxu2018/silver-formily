Shared TypeScript configuration for Silver Formily workspaces.

> This is an internal workspace (`private: true`) and is not published to npm.

## Installation

```bash
pnpm --filter '<workspace-name>' add '@silver-formily/typescript-config@workspace:*'
```

Replace `<workspace-name>` with the consuming workspace name.

## Features

Provides `base.json`, `legacy-library.json`, `vue-library.json`, `docs.json`, and `docs-vue-jsx.json` presets.
