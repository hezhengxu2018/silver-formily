[简体中文](https://github.com/hezhengxu2018/silver-formily/blob/main/packages/typescript-config/README.md) | [English](https://github.com/hezhengxu2018/silver-formily/blob/main/packages/typescript-config/README.en.md)

Silver Formily 各工作区共享的 TypeScript 配置。

> 本包为仓库内部工作区（`private: true`），不发布到 npm。

## 安装

```bash
pnpm --filter '<workspace-name>' add '@silver-formily/typescript-config@workspace:*'
```

将 `<workspace-name>` 替换为消费该包的工作区名称。

## 功能

提供 `base.json`、`legacy-library.json`、`vue-library.json`、`docs.json` 和 `docs-vue-jsx.json` 配置。
